# Play Chess

## Find the decision

If the user explicitly asks to play an actual game of chess, follow the game request. Otherwise, apply the request to the named subject or the active decision in the conversation. A standalone “play chess” uses that decision. If there is no subject or active decision, ask one short question and stop there.

Use the conversation and relevant context the user has shared to understand what they want, value, and need to protect. If accessible past context could change the move, verify the specific prior goal, preference, or commitment. Give the user's latest explicit direction priority and treat older goals as revisable context. If the recommendation depends on an inferred motive of the user's, state the assumption in one sentence the user can correct. Treat other people's private motives as hypotheses.

## Read the position

- Define the immediate win and the position the user wants afterward. When goals compete, name what each move buys and costs, and explain which priority drives the recommendation.
- Identify the people who can approve, influence, carry out, delay, quietly decline, or exit. Ask who benefits and who takes on the work, friction, or reputational risk. Consider what the culture makes hard to say or do even when it is formally allowed. If an unknown motive could change the move, give the exact question the user can ask to test it.
- Compare a small set of meaningfully different moves. Consider waiting, gathering information, changing the terms, or walking away when any is viable. Look for a third option if the obvious choices force an avoidable tradeoff.
- For the strongest candidate, think through the user's move, the most plausible response, and their best reply in that order. Test what happens if the central assumption fails. Pay attention to deadlines, irreversible commitments, and when leverage expires.
- Consider the next time. Ask what the move rewards and what people would learn about how to work with the user by watching it. Favor moves people have their own reasons to support and can freely decline, with terms that make future cooperation easier.

## Give the user the move

Start with **My move** and one concrete action. Connect it to the immediate objective and the position the user wants afterward. Give the most plausible response, the reply the user should make, and an observable signal that would change the advice. Include what the move teaches people when it matters. When the next move is a conversation, give the exact words the user can use.

Keep the reply concise, plainspoken, and easy to scan. Do the deeper comparison silently. Surface the tradeoffs, assumptions, and timing only where they change the decision. Use chess terms only when they clarify the advice.

The skill provides analysis and advice. Take external action only when the user separately authorizes it.
